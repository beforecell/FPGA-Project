# 接线

板卡：HX4S20C / EG4S20BG256，板载原生4线SD和W25Q16启动Flash。TF留在板槽，总电源ON。

| 连接 | 用途 |
|---|---|
| USB-JTAG→电脑 | 配置FPGA SRAM；通过厂商BW可另行固化启动Flash |
| USB-UART Type-C→电脑 | CH340遥控/只读状态；备用低速维护通道 |
| 网口→电脑有线网卡 | 镜像写板载TF和读回比较 |
| HDMI_A→带声音显示器 | 本版图像/音频输出；避开Type-C旁HDMI_B的机械干涉 |
| 合适的独立电源 | 脱离电脑使用；电压电流按板卡手册，不靠USB芯片灯判断TF已供电 |

固化成功后，日常可不接JTAG、UART和网线。维护模式的黑屏是没有播放电路，不表示卡写成功或失败。进行真正断电检查时，应排除电脑USB反向供电并确认所有灯熄灭。

网卡选择以实际枚举为准。工具读取现有IPv4，协商板端临时地址，不修改主机IPv4、网关、DNS或防火墙；不同电脑/网络组合仍需实际验证。
