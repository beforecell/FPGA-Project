# 素材格式边界

外层ALPHA100为原始扇区资源目录，不是FAT32。扇区512字节，头magic ALPHA100，目录项A1ASSET1，头/目录各带CRC32。目录最多16项，其中可见媒体最多12项，另可带0或4个提示语音资源。具体偏移和校验以host/alpha_package.py中的build/inspect为准。

视频载荷为配套HXBBX005/BB48流；不是把MP4交给FPGA解码。普通MP4的H.264/H.265等由PC FFmpeg/OpenCV解码后再编码；视频目标640×480、25或30FPS。48kHz/mono/s16le PCM独立放置，含采样数、LBA和时间信息。图片为54字节头、24位BI_RGB BMP，正高度，宽高1..1920，板端适配。

主机生成数据只包括视频编码流、BMP、PCM、目录/时间/校验。三个分析结果由FPGA运行时生成；固定字体、旋转常量、阈值和提示音不是预制分析结果。CRC32检错不能等同密码学防篡改或数字签名认证。
