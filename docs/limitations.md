# 已知限制与待确认

- ARTF仍为诊断候选。配置SRAM读回一致性未解决；Flash校验和断电自启不能代替它，也不是赛事认证资格问题。
- 本轮没有第二台电脑、实际写卡、重烧固件、外部音画同步、最新bit长时耐久或重新人工画面/声音验收。
- 目标检测实际为最多4个独立运动区域框，不分类；相机运动、阴影、亮度变化、遮挡、静止目标、邻近合并仍可能误/漏框。
- 帧差为t与max(0,t-3)的灰度差、支持去噪和内轮廓；30FPS比较跨度100ms，不是帧插值/持久残影。分析可能有固定滞后，目标结果可回退一源帧，不宣传零延迟。
- 音频页为约5.46秒PCM时间波形和均方能量，FFT未启用。非1倍速声音/波形有既有限制，不承诺全部倍速完美音画同步。
- Alpha图片轮播固定5秒，没有新增可调周期。历史独立基础版可配周期，不在默认运行工程中；合成4张标准BMP仅离线生成，新组合未板测。
- 提供的两个历史演示IMG不在公共库：网口包2图；V5为4种尺寸而非4张全部640×480。新素材需要新验证。
- 官方IP和Windows字体不公开，恢复依赖需要合法取得对应资源；字体版本不同可能不能复原冻结字节。固件与合成测试镜像已在候选Release公开，接收者可按哈希导入或自行构建；第三方权利与诊断限制保持不变。
- 许可范围、比赛平台附件要求、报告/实物照片/连续演示视频不因代码上传而自动完成。
