# 制作素材、网口写卡与恢复

1. 添加本人有权使用的MP4/图片；选择25/30FPS、balanced或high，0秒表示全部；制作最终Alpha资源镜像。_assets/VIDEO01.img只是单视频中间产物。
2. PC等比缩放和编码视频，提取48kHz单声道16-bit原声音轨并检查非零/峰值/RMS。没有音轨或全零会如实提示，不合成道路声。资源包不含预生成帧差、检测框或波形。
3. 统一GUI选网口，刷新/选择直连网卡，进入TF维护模式，再连接设备。显示实际卡名称/CID/容量和就绪状态后选择完整IMG。
4. 点击写入并核对本次卡身份、覆盖LBA、大小和完整SHA，确认后写入。当前是资源包替换，不是FAT目录追加；想保留的媒体应一起重新打包。
5. 保持供电和网线，等写入与完整读回逐字节/完整SHA比较结束。进度条显示总进度：写入100%时总进度50%，读回完成才100%。超时重传会增加耗时，发送完不等于成功。
6. 校验通过再加载所选播放器，或对已经固化的板子完全断电重开。恢复播放会重新初始化读卡/缓存。

网卡1Gbps是链路协商速率，不是当前协议有效吞吐。历史32MB镜像写+读回96.609秒/29重传，只适用于那次本机测试，不承诺所有卡或电脑同速。取消、掉线、错误或未完成读回均按未完成处理，无跨断电续传保证。

公开分发不含历史TTS语音；打包器允许0或4条隐藏语音，缺少可选语音时使用0条。正常媒体PCM与按键滴声保留，不能用提示音冒充原视频声音。assets/Synthetic_Demo.img可由自有合成脚本生成，未获得新的实板验收。
