# 按键与开关

## ARTF按键与SW映射

“开/关”以实际界面状态为准。之前板上方向说明出现过不一致，首次看SW状态/界面，不能只凭朝上或朝下判断。

| 当前状态 | KEY1 | KEY2 | KEY3 | KEY4 |
|---|---|---|---|---|
| 两文件夹主页 | 返回主页 | 打开所选文件夹 | 视频/上 | 图片/下 |
| 视频或图片列表 | 上一级 | 打开 | 上一项 | 下一项 |
| 图片打开 | 返回列表 | 长按约1秒开/停5秒轮播 | 上一张 | 下一张 |
| 普通视频 | 返回视频列表 | 暂停/继续 | 短按上一源帧并暂停；长按上个视频 | 短按下一源帧并暂停；长按下个视频 |
| 四格总览 | 返回视频列表 | 暂停/继续 | 放大选中格 | 依次选择格 |
| 分析放大 | 返回四格 | 暂停/继续 | 短按上一帧；长按上个视图 | 短按下一帧；长按下个视图 |
| SW2调速 | 不退出调速 | 暂停/继续 | 减速，长按连续减0.25 | 加速，长按连续加0.25 |
| SW3关键帧 | 删除当前或此前最近标记 | 暂停/继续 | 跳到当前帧之前最近标记 | 记录当前源帧 |
| SW4参数 | 循环选参数 | 无效 | 加1，长按连续加4 | 减1，长按连续减4 |

| 开关 | 功能 |
|---|---|
| SW1 | 开启四分屏分析；关闭回普通原视频。四格依次原视频、帧差图、目标检测、音频波形。 |
| SW2 | 调速模式，只有关闭SW2退出。范围0.25～4倍；短按4加0.5，短按3在1倍以上减0.5、到1倍及以下减0.25，边界钳位。 |
| SW3 | 放大的原视频/帧差/目标检测中开启关键帧；四格与波形页忽略开启动作，之后进入放大也不自动启用，需再关开。SW2开启时已接受的SW3请求在SW2关闭后自动生效。 |
| SW4 | 图片/视频/波形画面中央参数面板：曝光、对比度、亮度、音量，0～100。关闭退出；优先级高于SW2/SW3。 |

最多4个关键帧/视频，重复不添加、满后不覆盖。按视频时间位置回溯/删除，重新下载或断电清空。普通视频首尾逐帧钳位；长按切资源视频，分析放大长按切视图，切换只短滴。

全屏视频和分析放大显示时间带，四格不显示。帧差在ARTF比较t与max(0,t-3)，前段历史钳位，不与上个视频末尾比较。暂停保持当前合法帧对；倒退会重新读取正确历史。目标框为最多四个运动区域，不输出车辆/行人类别；结果可能落后当前RGB一源帧，不是同步神经网络分割。

音量由SW4面板或上位机设置，默认20，0静音。显示器菜单的音量另调。四格和放大共用一条媒体音轨，不是四条音频叠加。非1倍速原声/波形存在既有限制，不能用于宣称所有倍速外部音画同步已完成。
